# Asset plan

For every scene: purpose, required type, framing/copy-safe zone, layers or video behavior, mobile/poster fallback, import path, provenance/rights and review status.

For connected generation: verify actual provider tools; record prompt, approved references, supported settings, credit/cost disclosure or uncertainty and applicable human approval. Save returned task reference and terminal result. Never record keys/tokens.

For manual generation: give copyable prompt/settings checklist, provider link and import instructions. Review output before use. Failures preserve design; paid retries need applicable approval.
