## Continuous-story export

Version 2 produces the Markdown handoff plus an exclusive adjacent `<handoff-basename>.motion/` directory containing `story.json`, `assets.json`, `runtime.js` and a completion manifest. A partial failure is not a complete handoff. Preserve existing files and retry with a new output name after review.

Load the local runtime and authored data into the host's existing stack. `ParallaxMotion.mountMotionStage(element, story, stageId, assets)` returns `seek(progress)`, `dispose()` and `ready`. Use native scroll bounds for normalized progress. Dispose on route teardown. Preserve host typography, components, forms and navigation. Any UI/UX tool may own the shell; no preview stylesheet is required for integration.

State whether approval covers motion or the saved integrated experience. Motion approval never approves an unseen full-site layout. Review projected reading-zone conflicts and clipping after resizing; retain complete semantic content and static alternatives.
